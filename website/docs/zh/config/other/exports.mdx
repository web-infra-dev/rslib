# exports

- **类型：** `boolean | ExportsOptions`
- **默认值：** `false`
- **命令行：** `--exports` / `--no-exports`

构建成功后，根据构建产物生成 `package.json` 的 `exports` 字段。设置为 `true` 或对象时开启，对象用于传入下方的选项。

```ts title="rslib.config.ts"
export default defineConfig({
  lib: [{ format: 'esm', dts: true }],
  exports: true,
});
```

`exports` 只能写在顶层，不能在 `lib` 项中设置。生成结果会整体替换已有的 `exports`，额外的子路径可以通过 [exports.custom](#exportscustom) 添加。watch 模式下，或通过 `--lib` 只构建部分 lib 时，不会生成。

## 生成规则

- 只导出 `esm` 和 `cjs` 格式的产物。
- `index` 入口导出为 `.`，`button/index` 导出为 `./button`，其他入口按入口名导出。
- 同时有 `esm` 和 `cjs` 产物时使用 `import`、`require` 条件，只有一种格式时直接使用产物路径。
- 开启了 [dts](/config/lib/dts) 的 lib 会一并导出类型声明文件，TypeScript 无法自动找到时添加 `types` 条件。
- bundle 模式下导出入口对应的 CSS 文件，bundleless 模式下不导出。

例如，构建带有 `index` 入口的 `esm` 和 `cjs` lib 会生成：

```json title="package.json"
{
  "exports": {
    ".": {
      "import": "./dist/esm/index.js",
      "require": "./dist/cjs/index.cjs"
    }
  }
}
```

## exports.include

- **类型：** `string[]`
- **默认值：** bundle 模式下为所有入口，bundleless 模式下为 `index`

要导出的产物，使用 glob 匹配产物相对输出目录的路径，扩展名可以省略。

例如，在 bundleless 模式下导出主入口和各组件目录的 `index`：

```ts title="rslib.config.ts"
export default defineConfig({
  lib: [{ format: 'esm', bundle: false }],
  exports: {
    include: ['index', '*/index'],
  },
});
```

## exports.exclude

- **类型：** `string[]`
- **默认值：** `[]`

从 `include` 选中的产物中排除，写法与 `include` 相同。

## exports.source

- **类型：** `boolean | string`
- **默认值：** `false`

导出入口的源文件，用于在开发时直接引用源码。

- `true`：`exports` 指向源文件，产物的导出写入 `publishConfig.exports`。
- 字符串：在每个 JS 子路径中添加以此命名的条件，指向源文件，可以配合 TypeScript 的 [customConditions](https://www.typescriptlang.org/tsconfig/#customConditions) 或 [@rsbuild/plugin-source-build](https://github.com/rstackjs/rsbuild-plugin-source-build) 使用。

例如，`source: '@acme/source'` 会生成：

```json title="package.json"
{
  "exports": {
    ".": {
      "@acme/source": "./src/index.ts",
      "default": "./dist/index.js"
    }
  }
}
```

## exports.custom

- **类型：**

```ts
type ExportsCustomItem =
  | ExportsField
  | ((
      exports: ExportsField,
      context: { pkg: Record<string, unknown>; isPublish: boolean },
    ) => ExportsField | Promise<ExportsField>);

type ExportsCustom = ExportsCustomItem | ExportsCustomItem[];
```

- **默认值：** `undefined`

自定义生成结果。

- 对象：添加子路径，与生成的子路径同名时替换。
- 函数：接收生成结果，返回最终的 exports。`source` 为 `true` 时，还会为 `publishConfig.exports` 调用一次，此时 `isPublish` 为 `true`。
- 数组：按顺序依次应用。

```ts title="rslib.config.ts"
export default defineConfig({
  exports: {
    custom: (exports) => ({
      ...exports,
      './package.json': './package.json',
    }),
  },
});
```

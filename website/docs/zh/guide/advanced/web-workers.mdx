# Web Workers

Rslib 支持使用标准的 `new Worker(new URL(..., import.meta.url))` 语法引用 Worker 源文件。

:::note

使用 Web Worker 时，仅支持生成 ESM 格式的产物，因此 [format](/config/lib/format) 必须设置为 `'esm'`（默认值）。

:::

## 创建 Worker

### 语法

创建 Worker 的基本语法如下：

```ts
new Worker(new URL('./worker.ts', import.meta.url));
```

Rslib 会重写 Worker URL，使其指向生成的 JavaScript 文件，并将 Worker 输出为 ES 模块：

```js
new Worker(new URL('./worker.js', import.meta.url), {
  type: 'module',
});
```

### 限制

Rslib 依赖静态分析，因此需要保持 `new URL(..., import.meta.url)` 表达式内联，不支持传入字符串或变量：

```ts
// 不支持
new Worker('./worker.ts');

// 不支持
const workerUrl = new URL('./worker.ts', import.meta.url);
new Worker(workerUrl);
```

更多 Worker 语法及其限制，请参考 [Rspack - Web Workers](https://rspack.rs/zh/guide/features/web-workers)。

## 产物模式

Web Worker 同时支持 [bundle 和 bundleless 模式](/guide/basic/output-structure#bundle--bundleless)。

### Bundle 模式

在 bundle 模式下，Rslib 会将 Worker 入口拆分为独立 chunk，并将 Worker 导入的模块打包到该 chunk 中。

### Bundleless 模式

将 [lib.bundle](/config/lib/bundle) 设置为 `false` 以使用 bundleless 模式：

```ts title="rslib.config.ts"
import { defineConfig } from '@rslib/core';

export default defineConfig({
  lib: [
    {
      bundle: false,
    },
  ],
});
```

在 bundleless 模式下，Rslib 会分别转换每个源模块，并将 Worker URL 和 Worker 内部的导入重写为对应的 ESM 产物路径。

以下面这组源码为例：

Rslib 会生成对应的 ESM 文件：

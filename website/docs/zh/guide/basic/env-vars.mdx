# 环境变量

本文介绍 Rslib 在生成库产物时，如何处理源码中的内置环境变量预设引用。

## 默认行为

Rslib 对不同产物格式中的内置 env 预设引用采用不同的处理方式：

| 产物格式        | `import.meta.env`         | `process.env.BASE_URL` / `process.env.ASSET_PREFIX` | 其他 `process.env.*` |
| --------------- | ------------------------- | --------------------------------------------------- | -------------------- |
| ESM             | 保留                      | 保留                                                | 保留                 |
| CJS             | 替换为 `undefined`        | 保留                                                | 保留                 |
| UMD / IIFE / MF | 内联 Rsbuild 的预设值     | 内联 Rsbuild 的预设值                               | 保留                 |

表格中的预设值遵循 Rsbuild 的环境变量处理方式，详见 [Rsbuild - 环境变量](https://rsbuild.rs/zh/guide/advanced/env-vars)。

保留的引用可以交由下游构建工具替换或目标运行时解析。

## 在构建时替换为具体的值

如果需要在构建库时将某个环境变量替换为具体的值，可以通过 [source.define](https://rsbuild.rs/zh/guide/advanced/env-vars#using-define) 显式定义：

```ts title="rslib.config.ts"
import { defineConfig } from '@rslib/core';

export default defineConfig({
  source: {
    define: {
      'import.meta.env.MODE': JSON.stringify('production'),
      'process.env.BASE_URL': JSON.stringify('/'),
    },
  },
});
```
